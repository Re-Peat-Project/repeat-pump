Installing the RE-PEAT Pompanisasi plugin

This page covers installing the plugin in QGIS, setting up the Python engine behind it, and checking that it works. Most of the time goes to the first engine setup, which takes a few minutes.

What you need

  • QGIS 4. The plugin was tested on QGIS 4.2.2 for Windows (the OSGeo4W installer). Its metadata allows QGIS 3.34 and later, but nobody has tried the wizard there yet.
  • Python 3.11 or newer on the same computer, with pip, venv and SSL included. The installer from python.org has them. The plugin uses this Python once, to build its own private environment.
  • An internet connection for the first engine setup. You need it again the first time stage 3 runs, because that stage downloads the WhiteboxTools program.
  • The plugin file repeat_pump_qgis.zip. It sits in the dist folder of the repository. To rebuild it, run python scripts/install_plugin.py --zip from the repository root.

Install the plugin

Pick one of the two ways.

From the zip file in QGIS

  1. In QGIS, open Plugins, then Manage and Install Plugins.
  2. Choose the Install from ZIP tab, select repeat_pump_qgis.zip, and click Install Plugin.
  3. Open the Installed tab and tick RE-PEAT Pompanisasi so it is enabled.

From a command line

This copies the plugin straight into the QGIS 4 default profile on Windows. Close QGIS first.

python scripts/install_plugin.py

For a different QGIS profile, pass its folder (the one that contains python/plugins):

python scripts/install_plugin.py --profile-dir "C:\path\to\profile"

Start QGIS and enable RE-PEAT Pompanisasi in the Plugin Manager, as in step 3 above.

Set up the engine

The analysis does not run inside QGIS. The plugin starts it in a separate Python environment, so its libraries cannot clash with the ones QGIS ships. The plugin builds that environment for you.

  1. Open the wizard with the water-drop button on the toolbar, or from Plugins, RE-PEAT Pompanisasi, Guided wizard.
  2. If the engine is missing, the wizard says so and the left side shows a Set up engine button. Click it.
  3. Wait. The plugin creates a folder named repeat_pump_env inside your QGIS profile and installs the engine into it. This needs internet and takes a few minutes. The same setup also runs by itself the first time you start a Processing algorithm, and you can start it from Processing Toolbox, RE-PEAT Pompanisasi, Set up engine environment.

If you use your own Python environment where repeat-pump is already installed, skip this step. Point the plugin at it with Plugins, RE-PEAT Pompanisasi, Set Python environment (advanced), or set the REPEAT_PUMP_PYTHON environment variable to the full path of its python.exe.

Check that it works

  • The wizard opens as a floating panel with the 11 stages listed on the left.
  • At the bottom of the stage list it says Engine ready.
  • The EN and ID buttons at the top right switch the wizard between English and Bahasa Indonesia. The wizard starts in Indonesian when QGIS itself is set to Indonesian, and in English otherwise. Messages written by the engine, such as warnings and the log, stay in English.

Then start your first run. On stage 1, open Run setup, choose where the output GeoPackage goes, pick your layers and click Create run. All layers must be saved files, not temporary layers. The wizard guide, with practice data and screenshots, walks through the rest.

Update or remove

To update, install the new zip over the old one, or run the install script again. When the engine inside the plugin is newer than the one in your environment, the wizard shows the Set up engine button again. Click it to refresh the environment. The Processing algorithms refresh it on their own.

To remove it, switch the plugin off and uninstall it in the Plugin Manager. The private environment stays behind. Delete the repeat_pump_env folder in your profile to reclaim the space. QGIS shows you the profile folder under Settings, User Profiles, Open Active Profile Folder.

Your results are not stored in the plugin. They live in the GeoPackage you chose for the run, next to run_config.yaml, run_state.json, run_report.md and run_report.json, plus a <name>_work folder for rasters and stage logs.

Troubleshooting

"No Python 3.11+ with venv/pip found"

The plugin needs a normal Python on the computer to build its environment. QGIS's own Python is not enough because it often lacks SSL. Install Python 3.11 or newer (for example from python.org), then click Set up engine again.

Engine setup fails or hangs

Setup downloads packages, so it needs a working internet connection. Behind a restrictive proxy or without internet it will fail. Run it again once you are online. Cancelling a stage kills the engine and anything it started, so a stuck run can always be stopped.

Stage 3 takes long the first time

It downloads the WhiteboxTools program on first use. Let it finish, or cancel and run it again when the connection is better.

"The layer must be saved to a file"

The engine reads layers from disk, so it cannot use a temporary (scratch) layer. Export the layer to a GeoPackage or shapefile, load that file, and choose it again.

A stage will not run and a field is highlighted

The stage needs a decision from you, such as a tolerance or a weight. The wizard never fills those in. Type the value in the highlighted field and the Run button turns on.

The plugin does not show up in QGIS

Check that QGIS is version 4 and that the plugin is ticked in the Installed tab. If you installed with the script, make sure it targeted the profile QGIS actually uses.

Without QGIS

The engine also runs on its own from a command line, with Python 3.11 or newer. Run this from the repository root in PowerShell:

py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m repeat_pump.cli --version
.venv\Scripts\python -m repeat_pump.cli run --config my_khg.yaml

Use any Python 3.11 or newer in place of py -3.13. Stages 2, 6 and 9 stop for review and exit with code 2. Continue with --accept 2, --accept 6 and --accept 9. The README has the full list of options.

Yang Anda butuhkan

  • QGIS 4. Plugin ini diuji pada QGIS 4.2.2 untuk Windows (pemasang OSGeo4W). Metadatanya mengizinkan QGIS 3.34 ke atas, tetapi wizard belum pernah dicoba di sana.
  • Python 3.11 atau lebih baru di komputer yang sama, lengkap dengan pip, venv, dan SSL. Pemasang dari python.org sudah memuat ketiganya. Plugin memakai Python ini satu kali untuk membangun lingkungan pribadinya.
  • Koneksi internet untuk penyiapan mesin pertama. Anda memerlukannya lagi saat tahap 3 dijalankan pertama kali, karena tahap itu mengunduh program WhiteboxTools.
  • Berkas plugin repeat_pump_qgis.zip. Berkas ini ada di folder dist pada repositori. Untuk membuatnya ulang, jalankan python scripts/install_plugin.py --zip dari folder utama repositori.

Pasang plugin

Pilih salah satu dari dua cara.

Dari berkas zip di QGIS

  1. Di QGIS, buka Plugins, lalu Manage and Install Plugins.
  2. Pilih tab Install from ZIP, pilih repeat_pump_qgis.zip, lalu klik Install Plugin.
  3. Buka tab Installed dan centang RE-PEAT Pompanisasi agar plugin aktif.

Dari command line

Perintah ini menyalin plugin langsung ke profil bawaan QGIS 4 di Windows. Tutup QGIS terlebih dahulu.

python scripts/install_plugin.py

Untuk profil QGIS lain, berikan foldernya (folder yang berisi python/plugins):

python scripts/install_plugin.py --profile-dir "C:\path\to\profile"

Jalankan QGIS dan aktifkan RE-PEAT Pompanisasi di Plugin Manager, seperti pada langkah 3 di atas.

Siapkan mesin

Analisis tidak berjalan di dalam QGIS. Plugin menjalankannya di lingkungan Python terpisah, sehingga pustakanya tidak bentrok dengan pustaka bawaan QGIS. Lingkungan itu dibangun otomatis oleh plugin.

  1. Buka wizard dengan tombol tetesan air di toolbar, atau lewat Plugins, RE-PEAT Pompanisasi, Guided wizard.
  2. Jika mesin belum ada, wizard memberi tahu dan di sisi kiri muncul tombol Siapkan mesin. Klik tombol itu.
  3. Tunggu. Plugin membuat folder bernama repeat_pump_env di dalam profil QGIS Anda dan memasang mesin ke dalamnya. Proses ini perlu internet dan memakan beberapa menit. Penyiapan yang sama juga berjalan sendiri saat Anda pertama kali menjalankan algoritma Processing, dan bisa dimulai dari Processing Toolbox, RE-PEAT Pompanisasi, Set up engine environment.

Jika Anda memakai lingkungan Python sendiri yang sudah berisi repeat-pump, lewati langkah ini. Arahkan plugin ke lingkungan itu lewat Plugins, RE-PEAT Pompanisasi, Set Python environment (advanced), atau atur variabel lingkungan REPEAT_PUMP_PYTHON ke jalur lengkap python.exe-nya.

Periksa hasilnya

  • Wizard terbuka sebagai panel mengambang dengan 11 tahap tercantum di sisi kiri.
  • Di bagian bawah daftar tahap tertulis Mesin siap.
  • Tombol EN dan ID di kanan atas mengganti bahasa wizard antara English dan Bahasa Indonesia. Wizard dimulai dalam bahasa Indonesia jika QGIS sendiri diatur ke bahasa Indonesia, dan dalam bahasa Inggris jika tidak. Pesan yang ditulis oleh mesin, seperti peringatan dan log, tetap berbahasa Inggris.

Setelah itu mulailah proses pertama Anda. Di tahap 1, buka Pengaturan proses, pilih lokasi GeoPackage keluaran, pilih layer Anda, lalu klik Buat proses. Semua layer harus berupa berkas yang tersimpan, bukan layer sementara. Panduan wizard, lengkap dengan data latihan dan tangkapan layar, menjelaskan langkah selanjutnya.

Perbarui atau hapus

Untuk memperbarui, pasang zip yang baru di atas yang lama, atau jalankan lagi skrip pemasangan. Saat mesin di dalam plugin lebih baru daripada mesin di lingkungan Anda, wizard menampilkan lagi tombol Siapkan mesin. Klik tombol itu untuk menyegarkan lingkungan. Algoritma Processing menyegarkannya sendiri.

Untuk menghapus, nonaktifkan plugin lalu copot di Plugin Manager. Lingkungan pribadinya tertinggal. Hapus folder repeat_pump_env di profil Anda untuk mengosongkan ruang. QGIS menampilkan folder profil di Settings, User Profiles, Open Active Profile Folder.

Hasil kerja Anda tidak disimpan di dalam plugin. Hasilnya ada di GeoPackage yang Anda pilih untuk proses tersebut, bersama run_config.yaml, run_state.json, run_report.md, dan run_report.json, ditambah folder <nama>_work untuk raster dan log tahap.

Pemecahan masalah

"No Python 3.11+ with venv/pip found"

Plugin memerlukan Python biasa di komputer untuk membangun lingkungannya. Python bawaan QGIS tidak cukup karena sering tidak memiliki SSL. Pasang Python 3.11 atau lebih baru (misalnya dari python.org), lalu klik Siapkan mesin lagi.

Penyiapan mesin gagal atau macet

Penyiapan mengunduh paket, jadi koneksi internet harus berfungsi. Di balik proxy yang ketat atau tanpa internet, penyiapan akan gagal. Jalankan lagi setelah Anda daring. Membatalkan sebuah tahap menghentikan mesin beserta semua proses yang dimulainya, sehingga proses yang macet selalu bisa dihentikan.

Tahap 3 lama pada kali pertama

Tahap ini mengunduh program WhiteboxTools saat pertama dipakai. Biarkan sampai selesai, atau batalkan dan jalankan lagi saat koneksi lebih baik.

"The layer must be saved to a file"

Mesin membaca layer dari disk, jadi tidak bisa memakai layer sementara (scratch). Ekspor layer ke GeoPackage atau shapefile, muat berkas itu, lalu pilih lagi.

Tahap tidak mau berjalan dan ada kolom yang disorot

Tahap itu memerlukan keputusan dari Anda, misalnya toleransi atau bobot. Wizard tidak pernah mengisinya. Ketik nilainya di kolom yang disorot, maka tombol Jalankan menyala.

Plugin tidak muncul di QGIS

Pastikan QGIS versi 4 dan plugin dicentang di tab Installed. Jika Anda memasang dengan skrip, pastikan skrip menuju profil yang benar-benar dipakai QGIS.

Tanpa QGIS

Mesin juga bisa berjalan sendiri dari command line, dengan Python 3.11 atau lebih baru. Jalankan ini dari folder utama repositori di PowerShell:

py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m repeat_pump.cli --version
.venv\Scripts\python -m repeat_pump.cli run --config my_khg.yaml

Gunakan Python 3.11 atau lebih baru mana pun sebagai pengganti py -3.13. Tahap 2, 6, dan 9 berhenti untuk ditinjau dan keluar dengan kode 2. Lanjutkan dengan --accept 2, --accept 6, dan --accept 9. README memuat daftar lengkap opsi.
